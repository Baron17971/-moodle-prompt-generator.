# מחולל פרומפטים ל-Moodle

אפליקציה למורים ליצירת פרומפטים לארבעה מסלולים: מטלה מעוצבת, יחידת SCORM, בוחן XML ומפת שאלות H5P Game Map.

קובץ ההפעלה: index.html
תבנית הפרומפט למפת שאלות: h5p-prompt.js

מסלול H5P כולל שתי תמונות לבחירה לפני הבנייה, מספר תחנות לבחירת המורה, חומר לימוד אופציונלי, סגנון חזותי ויחס תמונה (ברירת מחדל 16:7), והנחיות לבנייה, RTL, חיווי התקדמות ובדיקת חבילת .h5p.
